# Source provenance

- v4 settings/sidebar hooks in `USDiagnosticsUI.m` adapt the class names, root-settings detection, collection-row placement and inset bookkeeping from Chroma v0.51.0 `App/ModSettings.x` and Eevee v7.0.0 `Settings/EeveeSettingsUniversal.x.swift`. The entry explicitly requests the system `UIGlassEffect` like Chroma `Core/SGGlass.m`. It is not a port of Chroma's redesigned player or all Eevee glass surfaces.
- `Sources/Eevee/Premium/Account.pb.swift`, property replacement types, UCS/bootstrap extensions and server/bundled configuration policies are copied from Eevee v7.0.0. `ModifyRemoteConfiguration.swift` adapts the original modifier by removing its unused UIKit import, importing the renamed protobuf module and replacing a fatal snapshot load with a throwing load. Its actual attribute/remote-flag replacement tables are retained. `USPremiumModule.swift` wires it to the shared transaction without Orion. The supplied snapshots in `Resources/Configuration` are copied unchanged from the extracted Eevee bundle and embedded at build time to avoid missing IPA resource paths.
- `build-protobuf.sh` builds real apple/swift-protobuf tag 1.29.0 with module name EeveeSwiftProtobuf as required by the generated source. Source commit and the upstream LICENSE.txt are retained in build outputs and the package. Upstream: https://github.com/apple/swift-protobuf/tree/1.29.0 (Apache-2.0 with runtime library exception in LICENSE.txt). No empty replacement framework is used.

- `Sources/Eevee/Sharing/CleanShareLinks.swift` contains the original `CleanShareLinks` algorithm extracted from Eevee v7.0.0 `Sources/EeveeSpotify/CleanShareLinks.x.swift`, before the Orion hook declarations. Only its imports are adapted to Foundation. `USSharingBridge.swift` supplies explicit preference access and retained C bridge functions. `USUtilityHooks.m` ports the original clean-link interception, review prompt blocking and control-haptics behavior to the shared registry without Orion; it does not implement scrub haptics or every original share-sheet path. Original copyright/licensing remain applicable; no claim of full feature parity is made.

- `Sources/Chroma/Wire/Protobuf.h` and `.m` are copied unchanged from Chroma v0.51.0, commit `425d68bc1761e90a6b5828864720511bcef79fa9`, `tweak/Sources/Shared/Lyrics/`. Copyright and original terms remain with upstream. Separate integration permission was confirmed by the user for private testing; no public redistribution right is inferred.
- `Sources/Eevee/Feed/BrowsitaSectionStripper.swift` and `Tests/EeveeFeed/main.swift` are copied unchanged from EeveeSpotify v7.0.0, commit `d1da1d69715935e41d1dc97a25d11bcc42ebd170`, `Sources/EeveeSpotify/Premium/Helpers/` and `Tests/BrowsitaSectionStripper/`. See `EeveeSpotify-GPL-3.0.txt` and the upstream repository for authorship/history.
- The upstream feed test includes a no-op diagnostic function for its test executable only. Production uses the real NSLog diagnostic function in `USEeveeFeedModule.swift`.
- Core/Transport code and the adapter are newly authored integration work. Source notices are retained; this test kit is not a public combined distribution or a claim of resolved combined licensing.
